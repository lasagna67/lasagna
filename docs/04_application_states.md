
## Основные этапы

| Этап                      | Что происходит                                                               | Что делает клиент                                                               |
| ------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Черновик                  | Заявка еще не отправлена                                                     | Заполняет данные, выбирает продукт, сохраняет изменения                         |
| Заявка отправлена         | Банк получил заявку                                                          | Видит подтверждение отправки                                                    |
| Проверка                  | Система проверяет данные компании, финансовые показатели и кредитную историю | Следит за ходом рассмотрения                                                    |
| Рассмотрение сотрудником  | Банкир изучает заявку, если автоматического решения недостаточно             | Ожидает решения или запроса уточнений                                           |
| Нужны уточнения           | Банку не хватает данных или нужны исправления                                | Отвечает на вопросы, исправляет разрешенные данные и повторно отправляет заявку |
| Одобрена                  | Банк предложил запрошенные условия                                           | Изучает предложение и договор                                                   |
| Предложены другие условия | Банк предлагает другой продукт, сумму, срок или обеспечение                  | Решает, подходит ли предложение                                                 |
| Договор подписан          | Подпись принята, выдача еще не завершена                                     | Видит, что оформление продолжается                                              |
| Кредит выдан              | Моделируемая выдача завершена; для овердрафта активирован лимит              | Видит итог оформления                                                           |
| Отказ                     | Банк принял отрицательное решение                                            | Видит понятную причину                                                          |
| Отменена клиентом         | Клиент отозвал заявку или отказался от предложения                           | Видит подтверждение отмены                                                      |
| Срок предложения истек    | Предложение не подписано вовремя                                             | Видит, что прежние условия больше недоступны                                    |

## Как меняются этапы

| Событие                                                      | Результат                                           |
| ------------------------------------------------------------ | --------------------------------------------------- |
| Клиент создал заявку                                         | Появляется черновик                                 |
| Клиент заполнил обязательные данные и отправил заявку        | Начинается проверка                                 |
| Все условия автоматического одобрения выполнены              | Клиент получает предложение на запрошенных условиях |
| Нужна дополнительная оценка                                  | Заявка поступает сотруднику                         |
| Сотрудник запросил сведения                                  | Заявка ожидает уточнений                            |
| Клиент ответил и повторно отправил заявку                    | Проверка выполняется заново в той же заявке         |
| Сотрудник закончил рассмотрение                              | Одобрение, другие условия или мотивированный отказ  |
| Выявлено подтвержденное основание для автоматического отказа | Заявка получает отказ                               |
| Клиент подписал действующий договор                          | Начинается оформление выдачи                        |
| Выдача успешно завершена                                     | Кредит считается выданным или лимит активированным  |
| Клиент отозвал заявку до подписания                          | Заявка отменяется                                   |
| Клиент отказался от предложения                              | Заявка отменяется                                   |
| Предложение не подписано до окончания срока                  | Предложение становится недействительным             |
