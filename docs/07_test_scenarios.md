## Как фиксировать результат

Для каждого сценария записываются дата, тестовые данные, что сделал пользователь, что показала система и итог: "пройден", "не пройден", "заблокирован" или "не проверен".

## Основные сценарии

| №                         | Действия                                                                                                         | Ожидаемый результат                                                                              |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1. Вход и компания        | Зарегистрироваться, войти, указать ИНН действующей компании                                                      | Компания найдена, представитель видит только доступные ему данные                                |
| 2. Черновик               | Создать заявку, указать цель, сумму и срок, сохранить, выйти и войти снова                                       | Данные сохранились, заявка осталась черновиком                                                   |
| 3. Подбор продукта        | Выбрать разные цели, суммы и сроки                                                                               | Показаны подходящие продукты; неподходящие условия объяснены                                     |
| 4. Отправка заявки        | Оставить обязательное поле пустым и отправить, затем исправить и отправить снова                                 | Сначала показана ошибка; после исправления заявка принята на рассмотрение                        |
| 5. Автоматическое решение | Использовать тестовую компанию с шестью месяцами стабильных финансов, хорошей кредитной историей и без просрочек | При выполнении всех правил появляется предложение на запрошенных условиях                        |
| 6. Ручное решение         | Загрузить финансовый файл или выбрать продукт, требующий участия сотрудника                                      | Заявка направлена сотруднику даже при хорошем балле                                              |
| 7. Уточнение              | Сотрудник запрашивает дополнительную информацию; клиент отвечает и отправляет заявку снова                       | Вопрос виден клиенту, ответ сохраняется, заявка продолжает рассмотрение                          |
| 8. Другие условия         | Запросить сумму, которая не проходит по платежеспособности                                                       | Сотрудник может предложить меньшую сумму или другой срок; клиент видит изменение условий         |
| 9. Отказ                  | Использовать компанию с подтвержденным прекращением деятельности или просрочкой 30 дней и более                  | Заявка получает отказ с понятной причиной                                                        |
| 10. Ошибка источника      | Имитировать недоступность реестра или кредитного бюро без подтвержденного стоп-фактора                           | Показана проблема проверки или назначено ручное рассмотрение; это не считается кредитным отказом |
| 11. Подписание            | Уполномоченный руководитель открывает действующее предложение и принимает договор                                | Договор подписан, заявка переходит к оформлению выдачи                                           |
| 12. Завершение            | Дождаться успешного завершения моделируемой выдачи                                                               | Кредит считается выданным, а для овердрафта активирован лимит                                    |
| 13. Нет права подписи     | Представитель компании без права подписи пытается подписать договор                                              | Подписание запрещено, руководитель по-прежнему может его выполнить                               |
| 14. Отмена и истечение    | Отозвать заявку, отказаться от предложения или дождаться окончания его срока                                     | Заявка получает соответствующий итог и не подписывается по старому предложению                   |
