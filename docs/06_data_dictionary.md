
## 1. Клиент и компания

| Данные                       | Что означают                                              | Откуда берем                              | Когда нужны                   |
| ---------------------------- | --------------------------------------------------------- | ----------------------------------------- | ----------------------------- |
| Имя и контакты представителя | Кто работает в кабинете и как с ним связаться             | Учетная запись                            | При работе в кабинете         |
| Компания и ИНН               | Какому бизнесу принадлежит заявка                         | Выбор компании и регистрационные сведения | Для каждой заявки             |
| Форма бизнеса                | ИП или юридическое лицо                                   | Реестр                                    | Для проверки компании         |
| Дата регистрации             | Позволяет определить возраст бизнеса                      | Реестр                                    | Для проверки условий продукта |
| Состояние бизнеса            | Действует, реорганизуется или прекратил деятельность      | Реестр                                    | Перед решением                |
| Полномочия представителя     | Может ли человек работать с заявкой и подписывать договор | Данные о представителе и его правах       | Для соответствующего действия |
| Счет компании                | Счет для оформления кредитного продукта                   | Сведения о счетах компании                | Для положительного решения    |

## 2. Кредитный запрос

| Данные | Что означают | Откуда берем | Когда нужны |
| --- | --- | --- | --- |
| Цель кредита | На что бизнесу нужны деньги | Указывает клиент | Всегда |
| Пояснение цели | Дополнительное описание потребности | Указывает клиент | Обязательно при выборе «Другая цель» |
| Продукт | Вид кредита, выбранный для потребности | Подбор и выбор клиента | Перед отправкой |
| Сумма | Сколько денег нужно; для овердрафта — лимит | Указывает клиент | Всегда |
| Срок | На какой период нужен обычный кредит | Указывает клиент | Для кредита с месячным сроком |
| Период использования | На сколько дней нужен овердрафт | Указывает клиент | Для овердрафта |
| Обеспечение | Предусмотрен ли залог | Условия продукта и выбор клиента | Перед отправкой |

## 3. Фактические финансы

| Данные                   | Что означают                                                                               | Откуда берем                                         | Когда нужны                         |
| ------------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------------------- | ----------------------------------- |
| Месяц                    | За какой завершенный месяц приведены показатели                                            | Финансовый источник или CSV                          | Для каждой строки истории           |
| Поступления              | Деньги от деятельности без кредитов, взносов собственника и переводов между своими счетами | Автоматически; при допустимой резервной загрузке CSV | Для оценки действующего бизнеса     |
| Операционные расходы     | Денежные выплаты по деятельности без налогов, изъятий собственника и платежей по кредитам  | Тот же источник                                      | Вместе с поступлениями              |
| Налоги                   | Налоговые выплаты за месяц                                                                 | Тот же источник                                      | Вместе с поступлениями              |
| Изъятия собственника     | Деньги, выведенные из бизнеса для личного использования                                    | Тот же источник                                      | Вместе с поступлениями              |
| Свободные деньги         | Поступления минус расходы, налоги и изъятия                                                | Рассчитывает система                                 | При финансовой оценке               |
| Источник и период данных | Откуда получены сведения и какие месяцы охватывают                                         | Фиксирует система                                    | Для проверки полноты и актуальности |

## 4. Кредитная история

| Данные | Что означают | Откуда берем | Когда нужны |
| --- | --- | --- | --- |
| Наличие и длительность истории | Есть ли сведения о прошлых кредитных обязательствах и за какой период | Отчет бюро кредитных историй | При рассмотрении |
| Действующие обязательства | Какие долги еще не погашены | Тот же отчет | Для учета долговой нагрузки |
| Платежи по действующим кредитам | Сколько бизнес уже должен платить | Тот же отчет | Для расчета доступного нового платежа |
| Текущая просрочка | Сумма неоплаченного вовремя долга и длительность задержки | Тот же отчет | Для проверки ограничений |
| Дата отчета | На какой момент действительны сведения | Тот же отчет | Для проверки актуальности |

Подтвержденное отсутствие кредитной истории отличается от ошибки получения отчета.

## 5. Дополнительные сведения

| Данные                    | Что означают                                     | Откуда берем                   | Когда нужны                       |
| ------------------------- | ------------------------------------------------ | ------------------------------ | --------------------------------- |
| Вид и описание залога     | Какое имущество предлагается в обеспечение       | Клиент                         | Если требуется залог              |
| Принадлежность имущества  | Уже принадлежит бизнесу или приобретается        | Клиент                         | Для залога                        |
| Заявленная стоимость      | Оценка имущества клиентом                        | Клиент                         | Для залога                        |
| Принятая банком стоимость | Стоимость, на которую банк опирается при решении | Заключение сотрудника          | Для одобрения с залогом           |
| Стоимость оборудования    | Бюджет покупки                                   | Клиент                         | Для кредита на оборудование       |
| Описание проекта          | Что планируется запустить или расширить          | Клиент                         | Для "Старта"                      |
| Бюджет проекта            | Статьи затрат и их общая сумма                   | Клиент                         | Для "Старта"                      |
| Собственные средства      | Деньги клиента, направляемые в проект            | Клиент; проверяет сотрудник    | Для "Старта"                      |
| Месяц начала продаж       | Когда проект начнет получать поступления         | Клиент                         | Для "Старта"                      |
| Денежный резерв           | Отдельный запас денег на платежи                 | Клиент; подтверждает сотрудник | Если нужен денежный план          |
| Прогноз по месяцам        | Ожидаемые поступления и выплаты на весь срок     | Клиент                         | Для "Старта" или по запросу банка |
| Ожидаемое поступление     | Дата, сумма и основание будущего поступления     | Клиент; проверяет сотрудник    | Для овердрафта                    |

## 6. Результаты рассмотрения

| Данные               | Что означают                                                                      | Кто формирует                               |
| -------------------- | --------------------------------------------------------------------------------- | ------------------------------------------- |
| Номер и этап заявки  | Как найти заявку и понять ход рассмотрения                                        | Система                                     |
| Итоги проверок       | Что установлено по компании, финансам и кредитной истории                         | Система и сотрудник                         |
| Балл                 | Оценка по правилам проекта; для инвестиционного кредита "Старт" не рассчитывается | Система                                     |
| Объяснение оценки    | Какие факторы повлияли на результат                                               | Система                                     |
| Запрос уточнений     | Что нужно дополнить или исправить                                                 | Сотрудник                                   |
| Ответ клиента        | Пояснения и исправленные сведения                                                 | Клиент                                      |
| Решение и причина    | Одобрение, другие условия или отказ и его объяснение                              | Система либо сотрудник по правилам продукта |
| Итоговые условия     | Продукт, сумма, срок, ставка, платежи и обеспечение                               | Предложение банка                           |
| Срок предложения     | До какого момента его можно принять                                               | Банк по правилам продукта                   |
| Договор и подписание | Какой договор предложен, кем и когда подписан                                     | Система и уполномоченный представитель      |
| Результат выдачи     | Завершена ли моделируемая выдача или активация лимита                             | Система                                     |
| История заявки       | Важные изменения, вопросы и решения                                               | Система                                     |
