# document

Файлы заявки: объект в S3 (бакет `S3_DOCUMENTS_BUCKET`) и метаданные в `application_documents`. Ключ объекта наружу не отдаётся. Пишет документ модуль, которому он принадлежит, в своей транзакции через `documentrepo.InsertDocument` — договор пишет `underwriting` при решении: файл загружается до транзакции, если она не прошла, файл остаётся без ссылок на него.

| Ручка | Что делает |
| --- | --- |
| `GET /documents/{id}/content` | Файл: клиенту — документы заявок своей компании (чужой неотличим от несуществующего, 404), сотруднику (`underwriter`, `admin`) — любые. Сбой хранилища — 503 |
