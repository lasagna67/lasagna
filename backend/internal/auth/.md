# auth

## Как закрыть ручку авторизацией

```go
apps := api.Group("/applications", auth.Authenticate)
apps.GET("", h.list)
apps.POST("/:id/decision", h.decide, auth.RequireRole(authdomain.RoleUnderwriter))
```

## Как получить данные пользователя в методах

```go
import authdomain "github.com/lasagna67/lasagna.git/internal/auth/domain"

claims, ok := authdomain.GetClaims(ctx)
if !ok {
	return autherrors.ErrUnauthenticated // ручка не закрыта Authenticate
}
```
