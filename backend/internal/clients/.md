# clients

HTTP-клиенты к внешним системам. В демо это моки из корня репозитория, в проде на их месте были бы настоящие ЕГРЮЛ, БКИ, УЦ и т.д.

Клиент — не сервис: у него нет бизнес-логики, таблиц и ручек. Он только отправляет запрос и переводит ответ в Go-структуры и ошибки.

## Как использовать в модуле

Сервис не зависит от клиента напрямую: он объявляет у себя интерфейс с нужным методом, а клиент подставляется при сборке в `internal/app/service.go`. В тестах вместо клиента — фейк.

```go
// internal/<модуль>/service
type Registry interface {
	GetCompany(ctx context.Context, inn string) (registryclient.Company, error)
}

// internal/app/service.go
registry := registryclient.New(cfg.Registry.URL, cfg.Registry.Timeout)
```

Ошибки клиента сервис переводит в свои: «не найдено» — в ошибку модуля, всё остальное — в «внешний сервис недоступен» (ручка отвечает 503). Пример — `internal/company/service`.
