# application

Заявка на кредит по контракту lasagna-credit-v1 — ядро для всех этапов, от черновика до выдачи. Статусы и переходы — `domain/domain.go`, метод на каждый переход; запрещённый переход — 409 `INVALID_STATE`. Этапы (`intake`, `review`) вызывают переходы отсюда и своих статусов не заводят.

Общее для этапов: ошибки — `errors`, объект заявки и формат ошибок для API — `dto`, чтение заявки, история статусов и ключи идемпотентности — `repo`.

Новые ручки отдают ошибки в общем формате `{"error": {"code", "message", "field_errors"}, "request_id"}`, деньги — целыми копейками, незаполненное — `null`.

Ключи идемпотентности лежат в `idempotency_keys`: область — пользователь, операция и ресурс (у создания ресурса ещё нет).
