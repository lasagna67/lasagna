# application

Заявка на кредит по контракту lasagna-credit-v1 — ядро для всех этапов, от черновика до выдачи. Статусы и переходы — `domain/domain.go`, метод на каждый переход; запрещённый переход — 409 `INVALID_STATE`. Этапы (`intake`, `underwriting`) вызывают переходы отсюда и своих статусов не заводят.

Общее для этапов: ошибки — `errors`, объект заявки и формат ошибок для API — `dto`, чтение заявки, история статусов и ключи идемпотентности — `repo`. Статус существующей заявки меняется только через `repo.Update`: блокировка строки, сверка revision, переход, история, revision + 1; данные этапа пишутся в той же транзакции.

Правила отправки — `domain/submit.go` (`CheckSubmit`): полнота запроса и условия продукта каталога (`repo.GetProduct`). Их вызывает `intake` при submit и resubmit (`intakedomain.Draft.CheckSubmit`), на них же опирается этап validation конвейера (модуль `pipeline`).

Конвейер пишет через тот же `repo.Update`, но с `UpdateCommand.RunID`: вместо revision сверяется запуск конвейера заявки (`processing_run_id`, новый при каждой отправке), устаревший запуск — `ErrStaleRun`. `History.Outbox` — события Kafka, которые пишутся в outbox в той же транзакции. Уведомления (`Notification`, `repo.InsertNotification`) пишутся вместе с изменением заявки, пока доставку не возьмёт отдельный модуль.

Новые ручки отдают ошибки в общем формате `{"error": {"code", "message", "field_errors"}, "request_id"}`, деньги — целыми копейками, незаполненное — `null`.

Ключи идемпотентности лежат в `idempotency_keys`: область — пользователь, операция и ресурс (у создания ресурса ещё нет).
